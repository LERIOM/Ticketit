    Le ticket
    
        
    Choisis un exemple ou écris ton propre ticket, puis lance l'analyse.
    
        
    
        
        
        
    
          
          
        
    
        
    Masquage, détection d'injection, résolution des cibles et faux executor sont le vrai code
          du projet. L'action proposée est une règle de démonstration en attendant l'agent (étape 8).
    
      
    
      
    
        
    
        
    
          
    1 · ENTRÉE
    Ce qui arrive
    En attente d'un ticket.
    
          
    2 · MASQUAGE
    Ce que voit le LLM
    Les données personnelles et les cibles deviennent des pseudonymes.
    
          
    3 · INJECTION
    Le ticket est-il piégé ?
    Règles + petit classifieur.
    
          
    4 · ACTION
    Ce que l'agent propose
    Simulé jusqu'à l'étape 8.
    
          
    5 · CIBLE
    Le code vérifie la cible
    Seuls IP externe, poste et compte sont acceptés.
    
          
    6 · EXECUTOR
    L'executor décide
    Niveaux 0 à 3, jamais le LLM.
